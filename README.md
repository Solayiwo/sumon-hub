# SuMon Hub 🛍️

A full-stack e-commerce web application that allows users to browse products, add items to a cart, and complete a checkout process.

## 🚀 Features

- Product listing page
- Product detail view
- Shopping cart system
- Checkout and order confirmation

## 🛠️ Tech Stack

- Frontend: React(vite), Tailwindcss, Shadcn
- Backend: Node.js (Express)
- Database: MySQL

## 📂 Project Structure

- frontend/ → React application (UI and client-side logic)
- backend/ → Node.js/Express API
  - models/ → Database schemas and entity definitions
  - db/ → SQL scripts and data files for database initialization
  - routes/ → API endpoint definitions
